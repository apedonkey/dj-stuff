# Tribe XR's menus, button by button

Every widget Blueprint in `Menus`, `TrackManager`, `MusicServices` (build 2304): 162 Blueprints, 547 controls, 547 bound events. Generated by `scripts/menu_catalog.py` from `uasset_tool dump` JSON; pseudo-code of every Blueprint is in `D:/TribeUE/tribe_assets/catalog/code/`.

How to read it:
- **Label** is the text on the control: a text block inside it, a Tribe widget's own label property (`TextLabel`, `ButtonText`, `Header` ...), or a string-table entry resolved to English. Where a control has no text of its own: *italic* is the text beside a checkbox, slider or dropdown; `run time:` is the text (or the dropdown options) the Blueprint sets while the game runs; icon `T_...` is an icon-only button's texture (its picture, or its button style's); `(list of W_X)` is a list whose rows are W_X widgets; `(panel W_X)` is an embedded panel; `[..., from its name]` is only the widget's name split into words, used when nothing else names the control.
- **Does** follows the event graph from the event's entry through its jumps, branches and sequences, and lists the calls that matter. The Blueprint's own functions are expanded a level (`Name() → ...`). Visibility, text, colour, sound and animation calls and plain getters are left out, so a control that only changes its own look shows "-".
- **Embeds** are the panels placed inside a widget in the designer; **creates** are widgets it spawns at run time; **used in** is the reverse.
